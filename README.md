# Airtel Clone Android App

Complete Android application with Airtel-style UI.

## Features
- ✅ Editable Balance (Tap to edit)
- ✅ Auto-scrolling Banner Carousel  
- ✅ Airtel UI Design
- ✅ Bottom Navigation
- ✅ Service Icons

## Build Instructions

### Local Build:
1. Open in Android Studio
2. Sync Gradle
3. Build → Build APK

### GitHub Actions:
Push to main branch, APK automatically builds!
